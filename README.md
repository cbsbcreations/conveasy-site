# conveasy.be

The Conveasy website: static HTML in five languages (nl, fr, en, tr, de).

- `src/` is the source. `python3 src/build.py` rebuilds the site.
- `docs/` is the built website. GitHub Pages serves this folder.
- `n8n/` holds a copy of the code behind the WhatsApp chat demo.
- `HANDOFF.md` explains how the two live demos are connected and what is still open.

Test address: https://cbsbcreations.github.io/conveasy-site/
